A command line application built in Java that allows you to track financial transactions for personal or business use. Deposits and payments are saved to a CSV file so your data persists between sessions. The ledger screen lets you view all transactions, filter by deposits or payments, and run date based reports — all displayed newest first.

Features

Add deposits and payments directly from the home screen.
All transactions saved automatically to transactions.csv.
View all transactions, deposits only, or payments only.
Run pre-built reports by date range.
Search transactions by vendor name.
Newest entries always displayed first.
